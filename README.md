LASUSCS Website V4

Mobile-first responsive public website for Lagos State University Sickle Cell Society.

Included:
- Exact LASUSCS logo
- Supplied event photographs
- Society Profile, Vision & Mission, History and Core Pillars
- Programme history with honest photo placeholders where event-specific evidence is not supplied
- Public reports: Symposium 2023, Project Hope 2024, Blood Donation Drive 2026
- Current executive names supplied by the society
- Proposed upcoming events clearly labelled proposed
- No SOLACE section
- No private Warriors Registry or internal records

Opening locally:
1. Extract the ZIP while preserving the folder structure.
2. Open lasuscs-site/index.html.
3. Keep the assets folder beside index.html.

For the most reliable local preview, a simple local web server can also be used.
